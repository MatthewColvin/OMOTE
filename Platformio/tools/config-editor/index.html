OMOTE Config Editor

Not connected

Connect to your OMOTE

Run this editor on your computer — the remote only needs WiFi and a small API.

cd Platformio/tools/config-editor
python -m http.server 8080

On the remote: Settings → Editor sync. Or use the buttons above. Exit with the Power button after saving.

Backup & restore

Package every JSON config file into one .omote file (zip). Use it before a risky deploy, for offline editing, or to copy your setup to another remote.

Config differs from remote

You have config in the editor that doesn’t match the remote. Choose what to keep — nothing is sent until you click Save to remote & reboot.
