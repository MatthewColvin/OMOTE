Connect to your OMOTE

Run this editor on your computer — the remote only needs WiFi and a small API.

cd Platformio/tools/config-editor
python -m http.server 8080

Hardware: use http://<device-IP> on the same Wi‑Fi. After a successful connect, the editor remembers the IP.

Connect enables editor sync on the remote (stays awake, sync screen) for the whole session. Use Leave session when done without reboot, or Power on the remote to reboot.

Backup & restore

Package every JSON config file into one .omote file (zip). Use it before a risky deploy, for offline editing, or to copy your setup to another remote.

Editor & remote settings

Saved in this browser unless noted. Deploy sends HA credentials to the remote.

Physical remote

Choose the PCB that matches your hardware. This changes the key layout in the Remote tab.

3661 adds Home, Guide, device keys (TV, Stream, STB…), and replaces the four color aux keys.

Layout from DeviceSettings.schema.json; values in DeviceSettings.json. Same files drive the on-device Settings → Device page.

Home Assistant

Entity lists load directly from HA in this browser. Credentials are written to HaSettings.json on the remote when you deploy.

Add this editor URL to http.cors_allowed_origins in Home Assistant configuration.yaml, then restart HA.

Config differs from remote

You have config in the editor that doesn’t match the remote. Choose what to keep — nothing is sent until you click Save to remote & reboot.
