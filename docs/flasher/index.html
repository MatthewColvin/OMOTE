OMOTE Rev1 flasher

Flash firmware and factory LittleFS over USB from the browser (Chrome or Edge).

Experimental fork build — Rev1 only. Rev5 / 3661 not supported here yet.
  1. Connect the OMOTE over USB.
  2. Put the device in download mode if your board requires it.
  3. Click install and pick the serial port when prompted.
  4. Allow erasing when asked (full flash recommended for first install).
Use Chrome or Edge on desktop (Web Serial required). Open this page via HTTPS (GitHub Pages).
